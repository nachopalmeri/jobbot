## Design Context

### Users
**Target audience**: Professionals in Argentina looking for jobs in tech/creative industries.
- Age range: 22-45
- Tech-savvy but not necessarily developers
- Looking for work while possibly employed or studying
- Values efficiency, hates wasting time on repetitive tasks

**Context**: Users access JobBot primarily via Telegram (mobile-first), also web dashboard. They want job alerts that match their profile without having to manually search multiple job boards.

### Brand Personality
**Voice**: Direct, encouraging, slightly informal (Argentine style)
**Tone**: Helpful without being pushy, professional but human
**3-word personality**: "Eficiente, accesible, confiable"

**Emotional goals**:
- Reduce anxiety about job searching
- Save time on repetitive tasks
- Feel in control of the job search process
- Celebrate small wins (interviews, offers)

### Aesthetic Direction
**Visual tone**: Modern Argentine tech startup - not too corporate (not LinkedIn), not too casual (not TikTok)

**Theme**: Light + Dark mode (user preference)
- Light: Clean, airy, professional
- Dark: Easy on eyes, reduces battery, modern feel

**Color palette**:
- Primary: Indigo/purple (trust, professionalism)
- Accent: Warm tones (approachability - Argentina-inspired)
- Neutrals: Warm grays, not cool

**Typography**:
- Display: Something distinctive (not Inter/Roboto/Plus Jakarta)
- Body: Highly readable, good screen legibility
- Argentine-friendly: Support for ñ and accents

**References**:
- Linear (motion quality)
- Vercel (simplicity)
- Bumeran/LinkedIn (job search context)
- Notion (clarity)

**Anti-references**:
- ❌ Generic AI slop (gradient purple-blue, dark with neon)
- ❌ Overused fonts (Inter, Roboto, Plus Jakarta)
- ❌ Glassmorphism everywhere
- ❌ "Hero metric" template layouts

### Design Principles
1. **Clarity first** - Every element should have a purpose
2. **Respect user's time** - No unnecessary steps, efficient interactions
3. **Celebrate progress** - Delight when user succeeds (applies, gets interview, offer)
4. **Argentine authentic** - Feel local, not imported copy
5. **Motion with purpose** - Animations should enhance, not distract

### Technical Constraints
- HTML/CSS/JS landing (static, fast)
- Chart.js for data visualization
- GSAP for animations
- Mobile-first responsive
- Accessibility: WCAG AA compliance
- prefers-reduced-motion support
