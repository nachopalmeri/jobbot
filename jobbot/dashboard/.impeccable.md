## Design Context

### Users
JobBot es una herramienta SaaS para profesionales en búsqueda activa de empleo en tecnología. Nuestros usuarios son:
- **Developers, designers, y profesionales tech** que aplican a múltiples posiciones semanalmente
- **Contexto de uso**: Interactúan con el dashboard durante la búsqueda (mañanas/tardes), entre reuniones, o en momentos de procrastinación productiva
- **Job to be done**: Automatizar y organizar la búsqueda de empleo para maximizar oportunidades sin perder tiempo en aplicaciones repetitivas
- **Emociones objetivo**: Confianza (sienten que el bot trabaja por ellos), claridad (visualizar progreso), y calma (reducir el caos de la búsqueda)

### Brand Personality
**3 palabras**: Inteligente, Eficiente, Moderno
- **Voz**: Directa y profesional pero cercana, sin tecnicismos innecesarios
- **Tono**: Optimista pero realista, celebrando pequeñas victorias sin ser hype
- **Emotional goals**: El usuario debe sentir que JobBot es su "aliado silencioso" que trabaja constantemente por ellos

### Aesthetic Direction
**Visual tone**: Minimalista profesional con toques de calidez tech
- **Referencias**: Linear.app (claridad), Notion (organización), Vercel (limpieza técnica)
- **Anti-referencias**: Evitar diseños "corporate aburrido" tipo Salesforce, o "techbro agresivo" tipo algunos dashboards de crypto
- **Tema**: Light mode primario con dark mode bien implementado. El dashboard debe sentirse como un espacio de trabajo limpio, no un "centro de control oscuro"

### Design Principles
1. **Progreso visible**: Cada métrica debe mostrar contexto (tendencias, comparativas) - la información sin contexto es solo datos
2. **Acción rápida**: La interfaz debe permitir aplicaciones y búsquedas en máximo 2 clicks
3. **Consistencia calmada**: Espaciado generoso pero no desperdiciado, ritmo visual que no agota
4. **Feedback inmediato**: Cada acción tiene respuesta visual clara en <300ms
5. **Mobile-first real**: El 70% de usuarios revisan jobs en mobile, el dashboard debe funcionar perfectamente en móvil

### Technical Constraints
- Next.js 16 + Tailwind CSS v4 + TypeScript
- shadcn/ui para componentes base
- Framer Motion para animaciones sutiles (no excesivas)
- Zustand para estado global, TanStack Query para server state
- Geist font (ya configurado en proyecto)
- W3C WCAG AA accessibility compliance
